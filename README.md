# entropytech-midia

Mídia pública das publicações do Instagram da Entropy (@entropytech_), usada pelo Metricool para agendar posts.

- Uma pasta por peça: `AAAA/MM-DD-<peca>/`
- Carrosséis: `01.jpg`, `02.jpg`… na ordem das telas (1080×1350)
- Reels: `reel.mp4` (1080×1920) + `capa.jpg`
- Stories: `story-01.jpg`…

Tudo aqui é público. Não suba prints com dados reais de clientes.
